# Draft Tasarım uygulama sayfaları

GitHub Pages: https://drafttasarim.github.io/

- /libalive/ — gerçek ekranlar, Pocket ses örnekleri, kullanım videosu ve ücretlendirme.
- /libalive/rehber/ — PDF ve fotoğraftan Türkçe sesli okuma rehberi.
- /shroomtrail/ — geliştirme aşamasındaki saha rehberi ve günlük.
- /cleanphoto/, /albiqo/, /paletivo/ — uygulama tanıtımları.
- /robots.txt — bu alan adındaki bütün uygulama sayfaları için OAI-SearchBot erişimi.

Mevcut bağımsız gizlilik depoları ve URL’leri korunur. ShroomTrail politikası drafttasarim/ShroomTrail-privacy deposundadır.

Statik HTML/CSS/JS; takip betiği, çerez, harici font veya üyelik yok. Ana dala push GitHub Pages yayınını tetikler. /robots.txt kökte tutulur; uygulama alt dizinine kopyalanmaz.

Apple’a göndermeden önce RELEASE-CHECKLIST.md uygulanır. Eğitim amaçlı GPTBot kuralı bu çalışmada değiştirilmedi. Arama erişimi indekslenme veya öneri garantisi değildir.

LibAlive ses örnekleri: Wite Tech / Kyutai Pocket TTS Turkish, CC BY 4.0. https://huggingface.co/wite-tech/pocket-tts-turkish . Tanıtım videosu gerçek eski sürüm kaydı ve açıkça belirtilen yapay zeka üretimi temsili sahne içerir. Ekranlarda özgün örnek metin kullanılır. ShroomTrail ekranları kullanıcı konumu içermeyen geliştirme sürümündendir.
